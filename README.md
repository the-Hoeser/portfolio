# Rudra — A Life in Progress

A personal digital archive: part portfolio, part field journal, part memory collection.

## Direction

The visual identity is an editorial field journal: warm paper, deep forest ink, restrained clay accents, expressive serif typography, precise mono labels, asymmetric image compositions and generous breathing room. The public experience should feel like an independent publication rather than a conventional developer portfolio.

## Run locally

```bash
npm install
npm run dev
```

## Deploy

This project is configured for Netlify. Connect the repository and use:
- Build command: `npm run build`
- Publish directory: `dist`

## Current scope

This first release establishes the responsive visual foundation and content-led public experience. Supabase authentication, media storage, private entries and the creator dashboard are planned as the next implementation phase; no upload or persistence functionality is claimed in this release.

## Content

Edit `src/content.js` to update the featured projects, introduction and archive copy.
